# Installation

## Stable release

To install AntCAM, run this command in your terminal:

```sh
uv add antcam
```

Or if you prefer to use `pip`:

```sh
pip install antcam
```

## From source

The source files for AntCAM can be downloaded from the [Github repo](https://github.com/TheAntTeam/antcam).

You can either clone the public repository:

```sh
git clone https://github.com/TheAntTeam/antcam
```

Or download the [tarball](https://github.com/TheAntTeam/antcam/tarball/main):

```sh
curl -OJL https://github.com/TheAntTeam/antcam/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd antcam
uv sync
```
